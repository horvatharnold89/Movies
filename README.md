# Movies App - Android Interview Challenge

## Overview

This is a simple Android app that searches for movies using the [OMDB API](http://www.omdbapi.com/). 

**Your task**: Review the code and refactor it to follow modern Android development best practices.

## What We're Looking For

We want to see your understanding of:

- **Clean Architecture** and separation of concerns
- **SOLID principles**
- **MVVM pattern**
- **Dependency Injection** (Hilt preferred, but Koin is acceptable if you haven't used Hilt recently)
- Modern Android development with **Jetpack Compose**

## Technical Stack

All dependencies are already configured - you can focus on development:

- Kotlin 2.0.21
- Jetpack Compose + Material 3
- Hilt or Koin (Dependency Injection)
- Retrofit + OkHttp
- Kotlinx Serialization
- Kotlin Coroutines
- ViewModel + StateFlow
- JUnit + MockK (for testing)

## Requirements

### Must Have:
- Proper architecture with clear separation of concerns
- Dependency injection implemented correctly
- Lifecycle-aware components
- Proper state management
- Error handling

### Nice to Have:
- Clean, efficient Compose UI
- Unit tests demonstrating your testing skills
- Edge case handling
